Drop a model file

FBX (binary or ASCII), Wavefront OBJ, glTF 2.0 (.gltf or .glb), a Blender .blend or a 3ds Max .max. Everything runs in this tab — parsed by a WebAssembly module and drawn with WebGL, never leaving your machine.

Drop the whole folder and everything under it comes with the model, which is what a download needs: it keeps its images in a subfolder and names them by relative path. Open folder does the same from the picker, which cannot reach into a subfolder on its own.

Embedded textures load on their own. A file that references images, an .mtl or a .bin by name and arrives without them says which it is waiting for; drop those in afterwards and it reads again.

Drag to orbit, shift-drag to pan, scroll to zoom. Click a part to pick it out; pull the explode slider to take the model apart.

Materials

Every material the scene uses, largest surface first. Set a colour, how metallic or rough it is, and how much it lets through — the file's own values are kept, so From file always puts one back.

Assignments are remembered for the file, and Save assignment writes them out as JSON. Drop that file in later — on its own or with the model — to apply it again.
